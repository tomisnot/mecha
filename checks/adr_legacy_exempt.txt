# ADR 豁免名单 —— `Required verification` 必填规则的**祖父条款**
#
# 用法：checks/adr_format_selfcheck.py 读本文件。
# 一行一个 note 文件名（相对 docs/v2/notes/implemented/）；# 起注释。
#
# 为什么有这份名单：`## Required verification`（这条决定要求什么验证）是 2026-09-25
# 立的**文档纪律 D5**，对**此后新写的** `implemented/` note 必填（见 docs/v2/ADR制度.md
# §3 规则 7）。**既有 note 不许回填** —— 回填等于改历史，而历史记录的价值恰恰在于
# "它当时是什么样"。本名单就是"规则生效时已存在"的**冻结快照**。
#
# 名单**不需要维护**：
#   * 某篇 legacy note 若被**改名**，改名后的文件不在此列 ⇒ 它会被要求补该节（红一次，显式）；
#   * 若被**删除**，留下的死条目只是空豁免（无害，不报错）。
# 因此本文件只在"新增一篇 legacy note"这种不可能发生的情况下才需要动。
#
# ⚠ 它只豁免"缺 `Required verification`"这一条；其余必填节（Problem / Decision /
# Consequences / Alternatives considered）**对全部 note 一律必填**，与生效日无关。
