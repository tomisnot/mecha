# Phase 4 AI 适配器：工具形态同构 dsh 原生件

> **状态**：implemented
> **作者**：mecha v2
> **日期**：2026-09-23

## Problem

愿景（§1.2）要工具"仿佛是自己的手脚"。v1 另起 MCP server、手写 TOOL_NAMES、
description 里塞实现词汇（"经 choke point"）、隐式回执键（D-15/D-25）。

## Decision

`mecha/tools.py` 定义形态层，六维度照 dsh 原生工具长（总纲 §7 Phase 4 表）：

- **注册**：`ToolRegistry.register → disposer`；宿主注入 `ctx.tools` 的接线归
  Phase 5，**不另起 MCP server**（ADR 另起-MCP-server）。
- **声明**：`define_tool` 构造即校验，`output.schema` 必须含 `required`
  （D-15 销号）。
- **命名**：snake_case 动词_宾语；`list_*`/`get_*` 视图名拒注册（视图是 schema
  投影不是工具）；`mecha_*` 前缀拒（OWN_PACKAGE）。
- **错误**：`MechaError.to_failure()` → `ToolFailure {message, info}` 对齐。
- **描述文体**：`banned_words` 注入式守卫，含实现词汇当场拒。
- **投影**：`schemas()` 白名单（MODEL_VISIBLE_FIELDS），无手写名单可漂
  （D-25 销号）。
- 判据：`checks/phase4_adapter_selfcheck.py` + `checks/vocabulary_selfcheck.py`
  （领域词守卫，扫描面扩到非 .py——D-1 销号）。

## Consequences

换来：形状与 dsh 原生工具一致，Phase 5 接线即"像手脚"。付出：真 dsh 注册 +
"没读文档的 AI 第一次做对"的快照验收要等 Phase 5 接 EL 才能测（本阶段只锁形状）。

## Alternatives considered

**否决：直接实现 MCP server 面。** 见 rejected/另起-MCP-server。
**否决：description 守卫用固定内置词表。** 领域词属消费项目，库写死 = 又一次
  示例值泄漏；改注入式 + 独立 vocabulary.txt（守卫数据与守卫逻辑分离）。
