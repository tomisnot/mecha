# CodeAct：账逐条即时写 · 异常也留痕 · 动作不写域状态

> **状态**：implemented
> **作者**：mecha v2
> **日期**：2026-09-26

## Problem

三处问题 + 一处需要定性的边界：

1. ⚠ **账"整段跑完才写"**：记账循环在 `run` **末尾** ⇒ **中途抛异常 = 整段无账**
   （已跑过的步也一起丢）。
2. ⚠ **只捕 `MechaError`**：其它异常**既穿透、又不落账**（与 A1 同病）。
3. ⚠ **文档比代码大**：docstring 写"动作集 = **Surface 已注册项** + 内置 run/summary/estimate"，
   而代码只有四个内置（`run`/`summary`/`estimate`/`schema`）+ 经 `Surface.query` 的
   **注册 `query` 项**（**不触达** command/tool 面），且漏写了 `schema`。
4. 边界待定：`run` 动作走 `Surface.run` ⇒ **不过写权门**——**该不该过？**

## Decision

1. **账逐条即时写**：每个子调用**一有结果就 append 一条**（不再"跑完整段再写"），
   一段动作**共用一个 `call_id`** ⇒ 逐条写也**仍"整段可识别"**（不必新增批 id）。
2. **异常也留痕**：`except BaseException` ⇒ **记一条失败步**（`detail` = 类型名 + 消息）
   ⇒ **然后原样抛出**（与 A1 同一判据：**子调用已进入 ⇒ 副作用可能已发生**；留痕 ≠ 归一化）。
3. **文档改准**（不是无脑改小）：写明"**内置四个 + `Surface` 已注册的 `query` 项**；
   **不触达** command/tool 面"；并留话：**若将来要触达，必须同时回答"过不过写权门"**。
4. ⚠ **`run` 不过写权门是刻意的**（不改）：
   * `Surface.run` **不碰 Gate/History**（计算/演化面）；域状态的写发生在**宿主 handler 里的
     `gate.set`**（那一步过门）；
   * 把 `Surface.run` 塞进写权门，会要求"**只读计算也要先开闸**"——与既有的**读写分离**
     （只读命令在 `LOCKED` 下照样可调）冲突，**会弄死 EL 的演化**；
   * ⭐ **给 CodeAct 加闸也挡不住**：`Surface.run` 是**公开面**，任何宿主代码都能直接调
     ⇒ 在 CodeAct 这一条路上设卡，旁边还有十扇门。

## Consequences

**换来**：中途崩溃/异常时**已跑过的步都在史里**；一段仍可用 `call_id` 串；文档与代码逐项对齐。

**付出 / 放弃**：

- ⚠ **放弃"一段一条账"**：史事件数变多（**N 步 = N 条**）——**行为变更**，按 `codeact.*`
  计数/对账的消费者要按"每步一条"读（`call_id` 不变，仍是同一段）。
- ⚠ **放弃把 `Surface.run` 纳入写权门** ⇒ **明确留下一条边界**：
  **若某项目的引擎 `run` 在 Gate 之外改自己的存储**（"域状态外置"），
  那么 **CodeAct 这条路径不受写权闸管辖**。⇒ **正解是让宿主的写经 Gate**，不是给 CodeAct 加闸。
- **放弃"把动作集补成全部注册项"**：① 那会把"受限动作解释器"变成通用入口；
  ② R1/n=2（没有第二个消费者要求）；③ 真要做必须先回答"过不过门"，不能只加一支 `_dispatch`。
- **放弃"用 `finally` 兜底写账"**（比逐条写便宜）：`finally` 兜得住异常，**兜不住硬崩**
  （进程被杀/断电）⇒ 逐条即时写才是这条债的正解。

## Alternatives considered

**否决：保持"整段跑完再写"，只在 `finally` 里兜。** 异常能兜，硬崩兜不住；
而"中途崩溃丢整段"正是这条债的原文（`codeact.py` 旧 Known Limitations）。

**否决：给 `CodeAct` 加一条可选写权门（`gate`/`channel` 注入）。** 见上：它是**一条路上的卡**，
挡不住 `Surface.run` 的其他调用者；真要治，治"**引擎的写**"（项目侧，经 Gate）。

**否决：把 `run` 触达的"物理演化"也算作"域状态改动"并纳入写权。**
那等于宣布"算就是写"——只读计算在现代部署里是**随时要跑**的（读权与写权分离是既有语义）。
