# 否决：把 Monitor（侧边栏）做成附属功能 / 允许写回

> **状态**：rejected — 侧边栏是第一交付物；写回路径会制造第二份真值
> **作者**：mecha v2
> **日期**：2026-09-23

## Problem

人类监控面（侧边栏）在新架构里排第几？能不能给它加"从 UI 直接改状态"的便利入口？

## Decision

**Monitor 是与 Gate/History/Surface 并列的第一层**，不是附属（总纲 §5.2④；§1.2 事实二"侧边栏是第一交付物"）。**只读，无任何写回路径**。两层信任：概括层（derived，必须标明派生）+ 原始层（authoritative，History 本身）。硬纪律：**概括必须能从原始推出；不一致时原始赢，且概括必须显示为存疑**。

## Consequences

换来：人类监控面不污染真值；两层信任可对账。付出：侧边栏不能就地编辑，改状态必须走 Gate。

**重新考虑条件**：若出现"人类在监控面发起的修正"确有需求，它**必须**表现为一次经 Gate 的 `set`（actor=human），而不是 Monitor 自有写口——届时写取代 note 说明通道。

## Alternatives considered

**否决：Monitor 加写回按钮。** 立刻产生绕过 Gate 的第二条写路径，违反硬纪律 1。
**否决：概括层不落原始层引用。** 无法对账，"自己写的概括"变成不可证伪的第二真值。
