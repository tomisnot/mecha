# 否决：把写权门做成包装层 / 门面 / schema 省略

> **状态**：rejected — 直接或替代调用方一旦能绕过，门就不存在
> **作者**：mecha v2
> **日期**：2026-09-23

## Problem

Gate 落在哪一层最省事？包装 `set`、在 schema 里省略某些键、加个前置监听器，都比改执行器轻。

## Decision

**门必须在落地执行器上**（总纲 §5.2① + dsh `packages/AGENTS.md:14`："Schema omission、门面、包装层、监听器顺序都不是强制——当直接或替代调用方能绕过时；必须经执行器测拒绝"）。硬纪律 1 同义。判据**必须**经执行器构造拒绝用例，不接受"包了一层所以安全"。

## Consequences

换来：AI 无法绕过 seam 直写域状态（Phase 1 洞 1 的可测判据）。付出：executor 变重，`set` 的四步顺序不可换。

**重新考虑条件**：无。这条是 L1/L3 的结构前提；若某天包装层被证明不可能被绕过（同进程无其他入口 + 语言级私有性），届时写取代 note 说明证据。

## Alternatives considered

**否决：schema 省略敏感键。** 直接调用仍可传。
**否决：前置监听器拦截。** 监听器顺序可被绕过，且 `tools/execute` 类环绕层能替换参数。
