# 真机验收清单（设计层③）—— 三家真起 · 一个 dsh · AI 真调工具 · 真切手动开窗 · 真热更新

> ⚠ 这份是**给用户照着点**的清单，不是判据。判据是 `checks/` 里那 30 项 + 端到端那条。
> ⚠ **越靠前越可能出问题**（按"已经真的炸过"的顺序排的）。

## 0. 前置（先做这两步，否则容易看到假故障）

```bat
cd <框架仓>
python -m mecha --stop          :: 清掉上一轮可能留下的 launcher（⚠ 别用任务管理器强杀）
```
- ⚠ 确认 `mecha_roots.txt` 在（一行一个仓路径；`mecha_roots.txt.example` 是模板）；
- 起：**双击 `start_mecha.pyw`**（无黑框）或 `python -m mecha --all`。
  ⚠ `--all` 会**立刻起三家 + dsh**；不带 `--all` 只开面板，点「启动 ▸」才起。

## 1. 面板（人的入口）

- [ ] 四行都在：**ML Toolbox / Energy Level / Get Paper / dsh**（左栏也要有 dsh）；
- [ ] 每行是 `站点名 · 简介` + **存活滑块** + **写权栏**（「切到手动」/「交还给 AI」）；
- [ ] 底部有那句 **"关掉浏览器不会停服务"** 的提示。

## 2. ⭐ 点「启动 ▸」⇒ 三家**都就绪**

⚠ **上一次就是在这里炸的**：`backend_protocol：后端 ML（http://127.0.0.1::62499/mcp）`
（后端 URL 拼出**双冒号** ⇒ **AI 那条腿从来没接上过真项目**，`949458d` 修）。
- [ ] 三家徽章变**就绪**（不是 `stopped`、不是 `启动失败`）；
- [ ] 若有失败：看 `_mecha_runtime/logs/<id>.log`（各家的日志）与 `_mecha_runtime/launcher.log`。

## 3. ⭐⭐ AI **真的能调到三家的工具**（"一个 dsh 用所有软件"的核心）

- [ ] 在 dsh 里让 AI **各调一次三家各自的工具**（随便一个只读的就行）；
- [ ] 让 AI 调一次 **`read_write_authority`** ⇒ 应**一次报全在跑的三家**（每家一个 mode）。

## 4. ⭐ dsh 右栏：**一个按钮、N 个面板**（阶段①做的）

- [ ] 会话头部（对话框上面）**只有一个**「◈ 监控」按钮（修之前是**每项目一个** ⇒ 三个）；
- [ ] 点它 ⇒ 右栏打开 ⇒ **每个项目一个 tab**；
- [ ] ⭐⭐ **每个 tab 各显示【自己】那个项目的账**（⚠ 修之前它们会读**同一份** —— 那是同一个 bug 的另一面）。

## 5. ⭐ 切手动（写权切换，不动进程）

- [ ] 点 ML 或 EL 的「切到手动」⇒ **真开窗**（⚠ 首次建窗口要**几秒**，框架给 60s 超时）；
- [ ] 写权栏变「**人工持有**」；面板与 dsh **不关闭**，只是**待命**（写被拒、读照常）；
- [ ] 点「交还给 AI」⇒ 写权回去，**窗口不关**（切写权不动进程/连接）；
- [ ] GP 的人面是**它自己的 Web 工作台**（不是窗口）—— 这是设计如此。

## 6. ⭐ 热更新（改代码 ⇒ 关开滑块）

- [ ] 改一行某家的代码（比如一句日志文案）；
- [ ] 把**它**的存活滑块**关掉再打开** ⇒ 该软件**新 pid**；
- [ ] **dsh 不重启、会话不断、别家不受影响**；
- [ ] ⚠ 若热更新**新增了工具**：dsh 可能仍拿旧工具表（SDK 发不出 `tools/list_changed`）
      ⇒ 把 **dsh 那行的滑块关开一次**（= 重连）。

## 7. 收尾

- [ ] 面板底部「收尾退出」**或**双击 `stop_mecha.pyw` ⇒ launcher **真的退出**
      （⚠ 修之前它**退不出**：`serve_forever()` 只认 Ctrl+C）；
- [ ] 退出后 `_mecha_runtime/` 里不该再有 `.page-port` / `supervisor.pid`。

## ⚠ 已知限制（不是 bug，别当故障）

| 限制 | 说明 |
|---|---|
| **6 个 patch 叠一起** | 三家各 2 个 ⇒ 并集 6 个；三份项目隔离 overlay 都改**同一个 `id: webserver`**（**整块替换**）⇒ **谁的块最后生效取决于并集顺序**。⚠ 且"**三家插件是否都真加载**"**从未验过**（要真 dsh + `--dump-config`）—— **这次就是第一次机会** |
| **dsh 的 `cwd` 只有一个**（取第一个站点） | ⇒ dsh 插件**必须用绝对路径**（设计 §1.1.1 已记） |
| **GP 的 tab 身份变了** | `pp-monitor` → `mecha-panel:GP` ⇒ 旧右栏历史可能要**重开一次** |
| **开窗要几秒** | ML 主窗口实测 **5.8 秒**（PyQt+matplotlib+pyqtgraph）⇒ 那是**正常的**，不是卡死 |
