# 框架不再硬依赖示例项目：跳过语义 · 严格模式 · 为什么是**部分**跳过

> **状态**：implemented
> **作者**：mecha v2（开源准备）
> **日期**：2026-09-26

## Problem

门禁**硬依赖示例项目（EL 仓）与本机路径**：5 个 `checks/` 里写着**指向 EL 仓的绝对路径**
当默认值（形如 `<盘符>:<本机路径>\Energy Level`），`phase5_*` 没有 EL 就直接红。

后果两条：① **陌生人 clone 下来跑不了门禁**（与开源相悖）；② **公开仓泄漏本机目录结构**
（就是"个人路径守卫"要治的那类）。

## Decision

**外部依赖缺失只有一种语义 ⇒ SKIP；且能拆的必须拆，不许整条跳过。**

1. **SKIP 由判据自己声明**：判据缺依赖时**末行打印 `SKIP: <原因>` 并 `exit 0`**；
   `run_all` 只负责**识别、按名列出、计入 SKIP**（"为什么跳过"只有判据自己知道）。
2. **严格模式 `--require-external`**（或 `MECHA_REQUIRE_EXTERNAL=1`）⇒ **跳过即失败**，
   给**有依赖的 CI** 用（否则那几条会因为"永远跳过"而事实上退休）。
   ⚠ **不留别名**（`--require-el` 直接换掉，按 `--open-gate` 先例）。
3. ⭐ **部分跳过，不是整条跳过**：`capability_map` 只跳**它确实依赖 EL 的那几组**
   （并表 diff / 真实消费者 grep / bridge 穿线核对），**L1 / L2 / L3 / L3+ / L7 一字不动**。
   **实证写这里**：缺 EL 时它照样打印 ——
   `✓ L1：32 个声明字段全部表内有行`、`✓ L2：28 条符号都在`、`✓ L3：28 条都点名真实判据`、
   `✓ L3+：28 条都在 run_all 调用树里`、`✓ L7 对偶：未登记的名字会被 L1 抓、假符号 0 命中`
   ⇒ **守卫不需要 EL 也能活**；**整条跳过会让"声明必须被消费"这套守卫在开源后整体失效**
   （那是最坏结果）。
4. **路径默认值一律删掉**：`EL_ROOT` / `TSC_ROOTS` **只读环境变量，缺了不猜**。
   ⚠ 陷阱（本批差点踩，已写进代码注释）：**只删默认值而不加守卫** ⇒ `Path("")` = 当前目录
   ⇒ `EL_MAP` 指向 **mecha 自己的** `docs/capabilities.md` ⇒ 比对变成"自己跟自己比" = **假绿**。

## Consequences

**换来**：陌生人 clone 下来门禁**全绿**（`0 FAIL`）；**"缺依赖"与"真失败"被机械区分**
（缺依赖 ⇒ SKIP；依赖在但判据失败 ⇒ **仍然 FAIL**，不许拿缺依赖掩盖真失败）。

**付出 / 放弃**：

- ⚠ **放弃"门禁永远真跑全部判据"**：缺依赖时那几条**不跑**（靠严格模式兜）。
- ⚠ **放弃绝对路径作为默认值**：要跑得显式给 `MECHA_EL_ROOT` / `MECHA_TSC_ROOT`。
- **放弃"缺依赖即红"的旧姿态**：它使陌生人无法使用整套门禁。
- **放弃给旧开关留兼容别名**（本仓先例：`--open-gate` 也是直接换掉）。

### 迁移须知

- 本机（有 EL / tsc）：`run_all` → **23 PASS / 0 FAIL / 0 SKIP**（行为不变）。
- 陌生人（都没有）：→ **19 PASS / 0 FAIL / 4 SKIP**，并**按名列出**跳过的四条。
- ⚠ **别把"缺依赖的 SKIP"当成通过**：要它证明"真的验过"，用 `--require-external`。

## Alternatives considered

**否决：`capability_map` 整条跳过。** 那会让 **L1/L2/L3/L3+（"声明必须被消费"）** 在开源后
**整体失效** —— 正是本会话花整轮才建起来的那套守卫。⇒ 能拆就拆（本 ADR 第 3 条）。

**否决：继续硬编码默认路径。** 泄漏本机结构 + 陌生人跑不了（本 ADR 要解决的两件事都还在）。

**否决：缺依赖即红。** 与开源目标直接冲突。

**否决：给 `--require-el` 留别名。** 两个外部依赖（EL、tsc）用一个名字不够用；而本仓先例是
**直接换掉、不留兼容期**（`--open-gate`）。

## Required verification

- **三态原文**（输出不过滤）：无外部依赖 ⇒ `19 PASS / 0 FAIL / 4 SKIP`（按名列出四条）；
  `--require-external` ⇒ 4 条转 `FAIL`；本机设齐 ⇒ `23 PASS / 0 FAIL / 0 SKIP`。
- **红线**：伪造一份 `exit 1` 的 tsc ⇒ **FAIL**（不是 SKIP）—— 堵住"拿缺依赖掩盖真失败"。
- **三步红证**：S1 干净绿（**并自证"实际读到 N 个文件"**，防"读不到的"冒充"没命中的"）；
  S2 往未登记的被跟踪文件塞特征 ⇒ 红；**S3 用合成假表**（登记 1 处 / 实际 2 处 ⇒ 红）——
  因为**免除表清零后 S3 没有对象**，不许因"无债"丢掉那段覆盖。
- **个人路径免除表 = 0 行**，且**不是靠放宽守卫**达成的（旧命中要么被改掉、要么被移出）。
