采用的方向：架构先消除错误空间，测试验证剩余的关键结构与结果。文档与测试都是工具，不能互相制造强制义务。

- 退役 ADR 格式、模块局限章节、散文计数、领域词黑名单及其豁免表。

- 监控声明使用合成站点测试公共投影契约；资产样例不再强制与所有项目声明同步。
- 重挂使用实际工具调用验证；保留权限、原始记录、失败透传、重连与真实协议测试。
- 默认核心套件；集成、资产、项目接入、发布扫描按范围选择。
- 红证不再普遍强制；历史案例仍可从 Git 与既有记录查询。

代价与边界：取消词法与文件形状扫描后，等价实现不会被旧符号限制，边界审查需要看真实依赖和行为。
